=== SISTEMA DE TIEMPO ===
- Cuenta regresiva. remainingMinutes arranca en 660 (11hs = 7am a 6pm)
- Cada 1s real se descuenta 1 minuto
- Viajar (caminar/bus) descuenta tiempo
- Error en minijuego descuenta 2 min (ScheduleTime / SpendTime)
- timeLabel muestra "HH : MM hs restantes"

=== SISTEMA DE VERGUENZA ===
- SetShameTimed(level, durationMinutes) activa verguenza por tiempo
- Al terminar el timer, fade out en shameFadeOutMinutes (default 3)
- shameActive / shameLevel usados por ShameBar.cs
- Mientras shameActive == true, cada tick descuenta shameTimeMultiplier (default 2) minutos en vez de 1
- El TimeFeedback.Flash() se dispara cada 3 ticks acelerados (shameFlashCooldown)

=== SUB-LOCATIONS (interiores de minijuegos) ===
- PushSubLocation / PopSubLocation con stack
- Push: oculta mapButton, muestra backButton
- Pop: al llegar a 0, vuelve a mostrar mapButton

=== ANIMACIONES DE NPCs (WORKFLOW) ===
Las animaciones se crean manualmente en Unity Editor, NO por script.

Proceso para cada NPC:
  1. Seleccionar el child "sprite" del NPC en la escena
  2. Window > Animation > Animation (Ctrl+6) -> Create -> guardar .anim
  3. Crear dos animaciones:
     - Idle: un solo keyframe con la imagen estatica (personaje_01.png)
     - Talk: alterna entre imagen normal y de apuntar (personaje_01.png <-> personaje_01a.png)
  4. Crear Animator Controller: Create > Animator Controller
  5. Agregar dos parametros Trigger: "Talk" e "Idle"
  6. Agregar los dos estados (Idle, Talk) con sus .anim
  7. Transiciones:
     - Idle -> Talk: sin Has Exit Time, condicion: Talk
     - Talk -> Idle: sin Has Exit Time, condicion: Idle
  8. Asignar controller al Animator del child "sprite"

NOTA: El Animator Controller debe crearse desde cero si Unity crashea.
Los parametros deben ser TRIGGERs, no Bools.
Condiciones de transicion: el parametro debe estar SELECCIONADO explicitamente,
no dejarlo en blanco (error: "uses parameter which does not exist in controller").
