===== UMBRAL - Contexto del proyecto =====

GENERAL:
- Juego 2D narrativo por días: main_menu, day_2 (la escena activa de trabajo)
- Unity 6, URP 2D, Input System
- Source: SEBASTIAN-INFORMAL, TextMeshPro para UI

SCRIPTS EXISTENTES:

PlayerController:
- click-to-move

PathDrawer:
- Pathfinding BFS sobre Waypoints, dibuja con LineRenderer
- TotalDistance se calcula al dibujar el camino
- ClearPath() para limpiar la línea (se llama al abrir el mapa)
- SetCurrentWaypoint() para sincronizar el origen después de viajar
- CalculateTravelOptions(distance, out walkTime, out busTime, out busCost)
  - walkTime = distance * 4 (minutos)
  - busTime = distance * 1 (minutos)
  - busCost = 750 (pesos)

Waypoint:
- Nodo de grafo con neighbors

Destination:
- Al clickear un edificio en el mapa, llama PathDrawer.CalculatePath() y muestra la card

MapToggle/MapClose:
- Abrir/cerrar vista de mapa
- lbl_day ya NO se togglea (queda visible siempre)
- MapToggle.OpenMap() también limpia la ruta con PathDrawer.ClearPath()

MapManager:
- Esqueleto, sin usar

SISTEMA DE CARTAS (Card.cs):
- 5 cards en escena: card_house, card_school, card_clinic, card_hospital, card_townhall
- Cada card tiene referencias serializadas a:
  - walkTimeLabel (txt_0 de btn_walk)
  - walkCostLabel (txt_1 de btn_walk, muestra "Gratis")
  - busTimeLabel (txt_0 de btn_bus)
  - busCostLabel (txt_1 de btn_bus, muestra "$ 750")
- OnEnable() actualiza los labels con CalculateTravelOptions()
- Close() desactiva la card
- OnWalk() agenda minutos de caminata, sincroniza waypoint, cambia edificio, cierra card+mapa
- OnBus() verifica CanAfford(), si no alcanza la plata no hace nada (la card sigue abierta);
  si alcanza, gasta dinero, agenda minutos, sincroniza waypoint, cambia edificio, cierra card+mapa
- CloseCardAndMap(): método privado que oculta la card y cierra el mapa

GAMEMANAGER (GameManager.cs):
- Singleton (Instance)
- currentBuildingName, currentDestinationWaypoint (Waypoint), currentLocation (string)
- allBuildings (BuildingInterior[]) - referencia a interiores de edificios
- timeLabel (TextMeshProUGUI) - label de día/hora (formato "Día X - HH : MM am/pm")
- moneyLabel (TextMeshProUGUI) - label de dinero (formato "$ XXXX")
- RELOJ: currentHour (7), currentMinute (0), currentDay (2)
  - REAL_SECONDS_PER_GAME_MINUTE = 1f (1 segundo real = 1 minuto juego)
  - Update() avanza naturalmente + procesa minutesToAdd
  - ScheduleMinutes(int), AddMinutes(int)
- DINERO: currentMoney = 2000
  - CanAfford(int), SpendMoney(int)
- UpdateLocation(): muestra/oculta interiores según currentLocation

BUILDING INTERIORS (BuildingInterior.cs):
- buildingName para identificación
- Show() / Hide() activan/desactivan el GameObject

TERMINAL MINIGAME (Assets/Scripts/Minigames/Terminal/):

ClickableButton:
- Botón con SpriteRenderer, hover/click opacidad, isCancel
- Press() -> isPressed = true, alpha bajo, dispara OnClick
- PressNoNotify() -> igual sin evento
- ResetButton() -> isPressed = false, alpha normal

TerminalMonitor:
- 3 monitores por terminal, cada uno con 7 ClickableButton[] (0-5 trámite, 6 OK)
- correctSequence, ticketOnComplete
- ProcessClick():
  - Si índice < 6: radio button (otros 5 se resetean)
  - Si acierto: currentStep++, button se queda presionado
  - Si error: currentStep = 0; si índice >= 6 (OK) se desclickea
- ShowTicketOnComplete(): desactiva botones, muestra ticket
- ResetMonitor(): currentStep = 0, resetea todos los botones

PlayerTerminal:
- 3 monitores secuenciales, mistakeCount
- Cancel: error +2min, reinicia
- Error en secuencia: mistakeCount++ +2min
- Último monitor completo: ticket aparece
- Ticket clickeado: activa ticketButton (serializado), cierra minigame

NpcTerminal:
- Bucle infinito NPC con delays aleatorios y sesgo 80% al botón correcto
- AutoExecute() con PressNoNotify()

Ticket:
- OnMouseDown() dispara OnCollected

TerminalTrigger:
- Activa el minigame al clickear un SpriteRenderer
